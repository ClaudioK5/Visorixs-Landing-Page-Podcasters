# Visorixs Landing Page

Compact product landing page for **Visorixs**.

CTAs → [envision-frontend-peach.vercel.app](https://envision-frontend-peach.vercel.app/)

## Develop

```bash
npm install
npm run dev
```

## Edit

- Product name, app URL, CTA text → `src/config/site.ts`
- Section copy → `src/content/copy.ts`
- Screenshots → `public/screenshots/` and `src/assets/`
